# อยู่กับโรคจิตเภท — เว็บไซต์ข้อมูลและการดูแล

เว็บไซต์ Static ภาษาไทยสำหรับผู้ป่วยโรคจิตเภท ครอบครัว และผู้ดูแล

## ไฟล์
- `index.html` — หน้าเว็บไซต์
- `styles.css` — รูปแบบและ Responsive Design
- `script.js` — เมนู, Dark Mode และเช็กลิสต์รายวัน

## เปิดใช้งาน
ดับเบิลคลิก `index.html` เพื่อดูเว็บบนเครื่องได้ทันที

## นำขึ้นเว็บไซต์จริง
สามารถอัปโหลดทั้ง 3 ไฟล์ไปยังบริการ Static Hosting เช่น GitHub Pages, Cloudflare Pages, Netlify หรือโฮสติ้งทั่วไป แล้วตั้ง `index.html` เป็นหน้าแรก

## หมายเหตุด้านสุขภาพ
เว็บไซต์นี้เป็นแหล่งข้อมูลเพื่อการศึกษา ไม่ใช่การวินิจฉัยหรือแผนการรักษาเฉพาะบุคคล ไม่ควรหยุดหรือปรับยาเอง

## แหล่งข้อมูลที่ใช้เป็นฐาน
- WHO — Schizophrenia (อัปเดต 11 September 2026)
- กรมสุขภาพจิต กระทรวงสาธารณสุข
- ศูนย์สุขภาพจิตที่ 7 กรมสุขภาพจิต
- คณะแพทยศาสตร์/ภาควิชาที่เผยแพร่แนวทางการรักษาทางจิตเวช

เว็บไซต์ตัวอย่างนี้ไม่มีระบบเก็บข้อมูลผู้ใช้บนเซิร์ฟเวอร์ เช็กลิสต์รายวันเก็บใน LocalStorage ของเบราว์เซอร์เท่านั้น
